Завдання 1. GPIO interrupt на FALLING, без debounce.

Кнопка: один контакт на GPIO 6, другий на GND. Підтяжка INPUT_PULLUP.
В ISR лише інкремент лічильника, друк у loop().

Очікуваний результат підтверджено: одне фізичне натискання дає кілька
interrupt. Відпускання теж інкрементує лічильник.
У моніторі після серії натискань count дійшов до 15.
