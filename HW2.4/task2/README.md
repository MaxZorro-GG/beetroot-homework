Завдання 2. Software debounce на основі часу, перевірка поза ISR.

Потрібно було лишити GPIO interrupt на FALLING і не обробляти
дрязкіт у самому перериванні. Якщо від попередньої прийнятої
події минуло менше 50 мс, новий фронт ігнорується. Перевірка
часу стоїть у loop().

Кнопка та сама: один контакт на GPIO 6, другий на GND, INPUT_PULLUP.
В ISR лише інкремент лічильника фронтів. У loop() подія приймається,
тільки якщо millis() - lastOk >= 50.

Очікуваний результат підтверджено: хибних спрацювань менше,
одне натискання дає один accepted і кілька ignore.
Спрацювання при відпусканні все ще можливе, бо рівень кнопки
тут не перевіряється.
