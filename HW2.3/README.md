Завдання: superloop, три незалежні світлодіоди в одному loop() без блокування.

LED1 на GPIO 4, період 200 мс.
LED2 на GPIO 5, період 500 мс.
LED3 на GPIO 6, період 1000 мс.

Довга ніжка світлодіода через резистор 220Ом на GPIO, коротка на мінус.
Живлення світлодіодів від піна ESP32, окремі 3,3 В не використовуються.

delay() і while() для очікування немає. Кожен світлодіод зберігає час
останнього перемикання і порівнює його з millis(). Якщо інтервал минув,
стан змінюється. Поки один чекає, loop() перевіряє інші, тому періоди
не залежать один від одного.
