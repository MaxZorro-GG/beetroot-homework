# Радар з автозахопленням цілі на ESP32

## Опис проєкту
Проєкт реалізує простий радар на базі ESP32, двох лазерних датчиків відстані VL53L1X та сервоприводу.  
Система може працювати в двох режимах: автоматичному та ручному.

## Як працює
- Два датчики VL53L1X розташовані на відстані один від одного і вимірюють відстань до об’єкта.
- Сервопривід повертає платформу з датчиками вліво-вправо.
- Якщо об’єкт потрапляє в зону видимості обох датчиків, радар намагається тримати його по центру (автозахоплення).
- Якщо об’єкт бачить лише один датчик — серва повертається в його бік.
- Якщо нічого не виявлено — виконується сканування в заданому діапазоні кутів.

## Режими роботи
| Режим   | Керування          | Опис                                      |
|---------|--------------------|-------------------------------------------|
| AUTO    | Автоматичний       | Радар сам шукає та супроводжує ціль      |
| MANUAL  | Енкодер + кнопка   | Кут встановлюється вручну енкодером      |

Перемикання режимів — натисканням кнопки енкодера.

## Переваги
- Два незалежні I2C-датчики (можна працювати одночасно без конфліктів адрес).
- Неблокуюча логіка (використання `millis()` замість `delay()`).
- Ручний режим з енкодером для точного позиціонування.
- Швидке сканування та реакція на появу цілі.
- Проста і зрозуміла логіка супроводу цілі за різницею відстаней.

## Запуск
1. Залити прошивку через PlatformIO.
2. Відкрити Serial Monitor (115200).
3. Перемикати режими кнопкою енкодера.

## Компоненти
- ESP32
- Сервопривід SG90 / MG90S
- Енкодер KY-040
- Блок живлення 5 В для серви (окрема земля з ESP32)
- 2× Лазерний далекомір на базі чіпа VL53L1X (Time-of-Flight). Вимірює відстань за часом польоту інфрачервоного лазерного імпульсу.
- 
Основні характеристики VL53L1X
- Діапазон вимірювання: до 4 м
- Мертва зона: 0–4 см
- Кут огляду: 27°
- Довжина хвилі лазера: 940 нм
- Інтерфейс: I2C
- Напруга живлення: 3–5 В
- Споживання: до 40 мА

Переваги
- Працює при денному світлі (на відміну від ультразвукових датчиків)
- Компактний розмір
- Добре підходить для радара / супроводу цілі

Підключення VL53L1X
| Пін модуля | Підключення          |
|------------|----------------------|
| VCC        | 3.3 В або 5 В        |
| GND        | GND                  |
| SCL        | I2C SCL              |
| SDA        | I2C SDA              |
| XSHUT      | GPIO (опціонально)   |
| GPIO1      | Не використовується  |
