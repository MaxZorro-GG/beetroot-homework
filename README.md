# beetroot-homework

Домашні завдання та міні-проєкти курсу Embedded Development (Beetroot Academy).
Основна плата — ESP32-S3-DevKitC-1, один проєкт на STM32F411 (Black Pill).
Збірка ESP32-проєктів — PlatformIO, STM32 — STM32CubeIDE.

| Папка | Що робить | Стек | Ключові теми |
|---|---|---|---|
| [HW2.1](HW2.1/) | Світлодіод у трьох режимах (миготіння / увімкнено / вимкнено), перемикання кнопкою, вимір часу ітерації superloop | Arduino (ESP32-S3) | GPIO, переривання, антидребезг, `micros()`, `constexpr`, `enum class` |
| [HW2.2](HW2.2/) | Вимірювання механічної затримки спрацювання реле | Arduino (ESP32-S3) | `micros()`, таймаут, брязкіт контактів, транзисторний ключ |
| [HW2.2/HW2.2.PWM](HW2.2/HW2.2.PWM/) | Швидкість двигуна програмним ШІМ, п'ять рівнів скважності кнопкою | Arduino (ESP32-S3) | LEDC ШІМ, транзисторний ключ, RC-фільтр від наводок |
| [HW2.3](HW2.3/) | Три світлодіоди з різними періодами в одному `loop()` без блокування | Arduino (ESP32-S3) | Superloop, неблокуючі таймінги, `millis()` |
| [HW2.4](HW2.4/) | Порівняння п'яти способів антидребезгу кнопки з висновками | Arduino (ESP32-S3) | GPIO interrupt, time-based і state-based debounce, polling, апаратний RC-фільтр |
| [HW2.5](HW2.5/) | Витяжний вентилятор за розкладом на апаратних таймерах, OLED, ручний пуск | Arduino (ESP32-S3) | Апаратні таймери, ISR, критична секція, watchdog, I2C OLED |
| [HW3.1](HW3.1/) | Світлодіод за освітленістю: LDR, ковзна середня, гістерезис | ESP-IDF (ESP32-S3) | ADC oneshot, SMA-фільтр, гістерезис |
| [HW3.2](HW3.2/) | Калібрування АЦП: ручна формула проти калібрування eFuse, похибка | ESP-IDF (ESP32-S3) | ADC oneshot, ADC calibration (curve fitting), аналіз похибки |
| [HW3.3](HW3.3/) | Потенціометр керує яскравістю світлодіода і кутом серви | ESP-IDF (ESP32-S3) | LEDC, незалежні таймери й канали ШІМ, ADC |
| [HW3.4](HW3.4/) | Синтезатор на пасивному зумері: мелодії та ручна гра з Serial | ESP-IDF (ESP32-S3) | LEDC, частота ШІМ, UART-ввід |
| [HW3.5](HW3.5/) | Серва повторює кут потенціометра 1:1 | ESP-IDF (ESP32-S3) | LEDC ШІМ для серви, ADC, масштабування діапазонів |
| [mini1](mini1/) | Датчик світла керує реле, три режими кнопкою BOOT | Arduino (ESP32-S3) | ADC, гістерезис, транзисторний ключ, реле |
| [radar](radar/) | Ультразвуковий радар: серва з HC-SR04, візуалізація в Processing | Arduino (ESP32-S3) | HC-SR04, серва, Serial-протокол, Processing, узгодження рівнів 5 → 3,3 В |
| [target-tracker-radar](target-tracker-radar/) | Радар з автозахопленням цілі на двох VL53L1X | Arduino (ESP32-S3) | I2C, два ToF-датчики VL53L1X, серва, автоматичне супроводження |
| [stm32f411-servo-button-led](stm32f411-servo-button-led/) | Кнопка вмикає плавний рух серви та мигання світлодіода | STM32 HAL (STM32F411) | TIM3 PWM, CubeMX, детект фронту кнопки, неблокуючий код на `HAL_GetTick()` |

Живлення 5 В навантажень (реле, серви, датчики) — від зовнішнього блока
живлення, GND спільний з платою.
