# Модуль 3.1 — LDR + проста ковзна середня (SMA) + гістерезис

Beetroot Academy, Embedded Development — Модуль 3, урок 1.

ESP32-S3 зчитує фоторезистор (LDR) через ADC1 у режимі **oneshot**, фільтрує значення
**простою ковзною середньою (SMA)** і вмикає світлодіод, коли темно.
Два пороги (**гістерезис**) прибирають мерехтіння при незначних коливаннях освітленості.

## Обладнання
- ESP32-S3-DevKitC-1
- Фоторезистор (LDR, GL5528) + резистор 10 кОм (подільник напруги)
- Світлодіод + резистор 220–330 Ом

## Підключення
| Компонент | Підключення |
|---|---|
| LDR | 3V3 → LDR → **GPIO4** (ADC1_CH3) |
| Резистор 10 кОм | GPIO4 → 10 кОм → GND |
| LED | **GPIO5** → 220 Ом → анод LED, катод → GND |

```
3V3 ──[ LDR ]──┬── GPIO4 (ADC1_CH3)
               │
             [10k]
               │
              GND
```
Темно → опір LDR зростає → напруга на GPIO4 падає → значення ADC менше.

## Програмна частина
- PlatformIO, фреймворк **ESP-IDF**
- API: `esp_adc/adc_oneshot.h`, 12 біт (0..4095), атенюація 12 dB
- Період опитування: 50 мс (20 Гц)

### SMA
Кільцевий буфер на `SMA_N = 16` відліків. Сума оновлюється за O(1):
віднімається найстаріший відлік, додається новий, `avg = sum / count`.

### Гістерезис
| Поріг | Значення | Дія |
|---|---|---|
| `TH_ON`  | 2200 | `sma < TH_ON` → LED **ON** (темно) |
| `TH_OFF` | 2800 | `sma > TH_OFF` → LED **OFF** (світло) |

Між порогами стан не змінюється, тому світлодіод не мерехтить.
Пороги підібрані за логом: світло ≈ 3650, датчик закритий долонею ≈ 1700–2100.

## Збірка та запуск
```bash
pio run -t upload
pio device monitor -b 115200
```
> На моїй платі прошивка і монітор працюють через рідний порт **USB** (USB-Serial/JTAG),
> консоль переключена в menuconfig: *ESP System Settings → Channel for console output → USB Serial/JTAG*.

## Результат
Фрагмент логу (закриваю датчик долонею і відкриваю):
```
raw=3655 sma=3653 led=0
raw=2931 sma=3547 led=0
raw=2001 sma=2566 led=0
raw=1903 sma=2194 led=1   <- sma < 2200, LED ON
raw=2087 sma=2141 led=1
raw=3140 sma=2252 led=1   <- відкрив, LED ще тримається
raw=3527 sma=2765 led=1
raw=3533 sma=2858 led=0   <- sma > 2800, LED OFF
```

### Спостереження
Одразу після ввімкнення `raw` підскакує на ~150–180 одиниць: світло самого світлодіода
потрапляє на LDR. Без гістерезису це спричинило б мерехтіння (LED → світліше → вимк → темніше → увімк).
Два пороги із зазором 600 повністю прибирають цей ефект.
