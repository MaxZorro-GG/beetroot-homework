# Радар на ESP32-S3

Ультразвуковий радар: сервопривід гойдає датчик HC-SR04 у секторі 60–120°.  
На кожному кроці вимірюється відстань.

## Як працює
- Немає об’єкта (або він далі 50 см**) — серва рухається, горить **зелений LED.
- Об’єкт у зоні ближче 50 см — серва зупиняється, зелений гасне, червоний LED швидко блимає.
- Кут і відстань надсилаються в Serial (`кут,см`) для монітора або Processing.

## Піни
| Пристрій | GPIO |
|---|---|
| HC-SR04 Trig | 4 |
| HC-SR04 Echo | 5 |
| Червоний LED | 2 |
| Зелений LED | 1 |
| Серво SG90 | 6 |

Живлення датчика і серви — 5 V, GND спільний з платою.

## Запуск
1. Відкрити проєкт у PlatformIO.
2. Залити прошивку на ESP32-S3.
3. Serial Monitor: 115200.
4. За бажанням відкрити скетч Processing і вказати той самий COM-порт.
