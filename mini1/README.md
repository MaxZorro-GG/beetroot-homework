# mini1 — датчик світла та реле

Плата: ESP32-S3 N16R8.

## Що зроблено
Фоторезистор через подільник 10 кОм зчитується АЦП (GPIO 5).
GPIO 7 через резистор 10 кОм і транзистор BC547 вмикає модуль реле 5 В.
На контакти COM/NO можна підключити світлодіод або LED-стрічку.

Кнопка BOOT (GPIO 0) перемикає три режими:
1. звичайний — реле за освітленням (гістерезис)
2. реле завжди увімкнене
3. усе вимкнено

## Піни
- GPIO 5 — вхід фоторезистора
- GPIO 7 — база транзистора / керування реле
- GPIO 0 — BOOT
